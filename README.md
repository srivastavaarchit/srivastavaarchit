### 🎯 Near-Miss Incident Detection
> AI Crime Prevention · Computer Vision

An intelligent CCTV surveillance engine that **detects failed chain-snatching attempts** before they escalate — catching crimes that almost happened.

Runs a **6-stage multi-condition pipeline** on video frames: proximity detection, hand-motion speed analysis, victim reaction sensing, and timing filters. Fires alerts only when ≥5/7 conditions are met with ≥50% confidence, dramatically reducing false positives.

`YOLOv11` `PyTorch` `OpenCV` `ByteTrack` `Pandas`

**[📂 View Repository →](https://github.com/srivastavaarchit/Near-miss-Incident-Detection)**

### 🆘 RESQ — Disaster Management System
> AI Safety Platform · Hackathon Project

Real-time disaster response platform connecting victims to safety in seconds. Powered by **AutoQ** — a predictive routing engine that dynamically adapts as disaster zones evolve.

Delivers instant SOS alerts to police & volunteers, identifies nearby **Quell Zones**, enables live **Q-link communication**, and motivates rescuers with a **Q-Badge reward system**.

`React` `Node.js` `Firebase` `Groq AI` `Google Maps API`

**[📂 Repository →](https://github.com/srivastavaarchit/RESQ-Disaster-Management-System)  &nbsp;|&nbsp;  [🚀 Live Demo →](https://divyansh1610.github.io/RESQ/)**
